# 普娃家长指南

> 一本按性价比排序的**循证**教育决策指南。专答《高性价比人生指南》划界不答的那块：**孩子成绩普通时，教育上哪些事值得做、哪些是白花钱、哪些还会帮倒忙。**
>
> 每条写明花掉什么、换回什么、证据有多硬，来源只引期刊论文与官方文件。

## 这本书和《高性价比人生指南》的关系

《高性价比人生指南》已经覆盖了：

- **第 18 节**：养孩子要花多少钱、多少时间
- **第 20 节**：孩子刚出生那一年怎么带
- **第 27 节**：怀孕和生产要办哪些证
- **第 30 节**：上学以后孩子的**身体和心理安全窗口**（近视、脊柱、欺凌、抑郁、性侵、脑震荡、骑车年龄）

第 30 节开篇写得很清楚：

> 本节只回答一个问题：「别耽误学习」和「身体」撞在一起的时候，哪些事不能等。……**学业该不该那么卷，本节不讨论**，只给窗口和数字。

**本书补的就是这块。** 身体安全的事，去看原书第 30 节；本书只讲学业、成绩、补习、择校、亲子关系、要不要卷。

## 怎么读

- **不用全做**：这是一份按性价比排好的备选单，不是任务清单。挑走一两条就算数。
- **先看"说人话"**：每条都有一行大白话，把研究里的数字翻成日常说法。只看这一行就够拿主意。
- **"收益"栏原样留着全部数字**，想自己核对就看那一栏。
- **看"备注"栏**：适用人群、争议、例外都写在那里。只读标题会把条件丢掉。

### 每条建议长这样

```markdown
### 2. 别拿孩子的绝对分数跟别人比，看的是位置

- **成本**：0
- **说人话**：这次考 85 分，比上次 80 分高，但全班平均分从 75 涨到了 88——其实是退步了。
- **收益**：……
- **证据等级**：A
- **来源**：……
- **备注**：……
```

每章开头有一行成本标签：`> 成本标签：钱=0 ｜ 时间=少 ｜ 毅力=否 ｜ 收益=大 ｜ 口径=心理`。
钱 0/少/多/很多、时间 少/中/多/很多、毅力 否/些/是、收益 大/中/小、口径 **成绩/金钱/时间/心理**（四口径不互相折算）。

## 四种"换回什么"

本书把要换回的东西分成四样，**分开算，不互相折算**：

- **成绩**：学业表现的变化（标准化测验、GPA、升学结果）
- **金钱**：教育支出省下或花掉多少
- **时间**：家长和孩子的时间被占掉多少
- **心理**：孩子的心理健康、亲子关系、学习动机

「成绩提高 5 分」和「每年省 5000 元」不在一把尺子上。

## 证据分级

| 等级 | 含义 |
|------|------|
| **A** | 有具体数字可查，出处是多项研究合并起来的荟萃分析、跟踪很多人很多年的大型队列，或者随机分组的试验（RCT） |
| **B** | 有研究支持，但说不出一个确切数字；或者只有小样本、单独一项研究撑着 |
| **C** | 作者自己的经验，或者大家公认的做法，没有直接的研究文献 |

**重要提醒**：教育研究里随机分组试验（RCT）很少，绝大多数是**观察性研究**——只能说明"有关联"，说明不了"谁导致谁"。A 级只说明"有具体数字、出处可核"，**不说明这个数字一定是因果**。哪一种是因果，看"收益"栏：写着"随机分成两组"的是前者，写着"只记录、不分组"的是后者。

有争议的条目会标注「**争议**」并列出反方证据。

## 边界

这本书给的是通用口径，**不替代老师、医生、心理咨询师**。涉及具体孩子的学习障碍、心理问题、升学政策，按书里的条目给方向和该找谁，别替专业人士下判断。

书里不推荐任何具体机构、课程、产品或老师。
