## W1：内容质量复审（优先级最高）

**为什么先做这个**：内容有错，检索页和发布都是白搭。且复审能发现结构性问题，影响后续。

- [ ] **1.1 通读全书**，检查逻辑连贯性（跨章引用是否准确、有无重复/矛盾）
- [ ] **1.2 事实抽查**：随机抽 8–10 条，逐条核对「数字 ↔ 来源」是否一一对应
- [ ] **1.3 争议标注检查**：确认所有争议条目都有反方证据（成长型思维、补习、辅导作业）
- [ ] **1.4 口径检查**：确认四口径（成绩/金钱/时间/心理）未被混淆折算
- [ ] **1.5 数字口径统一**：检查摘要里的数字与正文一致（如"d=0.05"、"12–16%/年"）
- [ ] **1.6 输出复审报告** → `docs/review-01.md`，列出问题清单 + 修复

**验收**：复审报告无未决问题；抽查条目 100% 数字可溯源。

## W2：检索页 index.html

**设计原则**：本书只有 9 章 69 条，**不照抄原书 1672 行的复杂度**。做最小可用版。

- [ ] **2.1 定功能范围**（YAGNI）：
  - 必做：加载 9 章正文 → 按关键词搜索 → 按章/口径/证据等级筛选 → 点击跳转
  - 不做：术语表、交叉引用弹窗、滚动 spy、GA 埋点
- [ ] **2.2 写 index.html**（单文件，无构建，无外部依赖）
  - 读取 `book/*.md`（fetch + 简单 Markdown 渲染）
  - 解析条目结构（`### N. 标题` + 成本标签注释）
  - 搜索框 + 筛选器（章 / 口径 / 证据等级）
- [ ] **2.3 本地验证**：起本地服务器，浏览器截图确认四种状态（loading/empty/error/success）
- [ ] **2.4 响应式验证**：桌面 + 手机两种宽度

**验收**：能搜到、能筛、能跳；手机端可用；无 JS 时降级到 README。
