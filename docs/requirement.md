# 需求：《普娃家长指南》

## 一句话

一本**循证**的家长决策指南，专答《高性价比人生指南》划界不答的那块——**孩子成绩普通（"普娃"）时，教育上哪些事值得做、哪些是白花钱、哪些还会帮倒忙**。

## 为什么需要它（目标用户替代方案测试）

| 目标用户 | 他今天怎么解决这个问题 | 现状痛点 | 本书提供什么 |
|---------|---------------------|---------|-------------|
| 孩子成绩中游的小学生家长 | 刷公众号/小红书、问群里的家长、听机构顾问 | 全是二手转述和机构话术，没有出处，互相矛盾 | 每条带原始文献/官方文件，标明证据等级 |
| 被"要不要报班/鸡娃"困住的初中家长 | 凭感觉、被焦虑推着走 | 花了大钱不知有没有用，没人给算账 | 用成本/收益/证据等级算清每一笔 |
| 想坚持"不卷"但心里没底的家长 | 靠信念硬扛，被周围人动摇 | 没有硬证据支撑自己的判断 | 给出"不卷"也有循证依据的条目 |

**三类用户都能回答"他今天怎么解决"**，不是伪需求。

## 与原书的关系（不重复）

- 原书第 18 节：养孩子的**钱和时间账**
- 原书第 20 节：刚出生的孩子**怎么带**
- 原书第 27 节：怀孕和生产**办证流程**
- 原书第 30 节：上学后孩子的**身体/心理安全窗口**（开篇明说"学业该不该那么卷，本节不讨论"）

**本书专攻原书明确回避的：学业、成绩、补习、择校、亲子冲突、要不要卷。**

## 成本可行性

- 无外部付费 API，纯文本写作 + 联网查证文献。成本 = 我的 token + 联网搜索次数。
- 发布：GitHub 公开仓库，免费。无服务器、无数据库。

## 核心体验的技术支撑

产品"灵魂" = **每条都能指回原始文献**。支撑方式：写作时逐条查证，来源栏给 DOI/官方文件链接，查不到就标 C 级（作者经验）或如实说"没查到"。**不允许编造文献**。

## 验收标准

1. 每条建议格式统一：成本 / 说人话 / 收益 / 证据等级 / 来源 / 备注
2. 证据等级 A/B/C 三级，标准照原书
3. 有争议的条目必须标注"争议"并给反方证据
4. 每个数字/结论都能指回来源栏里的链接
5. 配套 skill（查书规则），照原书 skill 写
6. 可在 GitHub Pages 静态托管

## 不做

- 不替家长下"该不该生/该不该鸡"的结论，只把账拆开
- 不推荐具体机构、课程、产品
- 不写没有证据支撑的"育儿鸡汤"
