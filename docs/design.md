## 条目格式（照原书）

```markdown
### N. 动词开头的条目标题
<!-- 成本标签: 钱=0/少/多 时间=少/中/多 毅力=否/些/是 收益=大/中/小 口径=成绩/金钱/时间/心理 -->
- 成本：花掉什么
- 说人话：一句话，把研究数字翻成日常话
- 收益：具体数字 + 研究设计（样本量/追踪年限）
- 证据等级：A/B/C
- 来源：作者 (年份). 标题. 期刊. DOI 或官方文件链接
- 备注：适用人群、争议、例外、反方证据
```

## 证据分级（照原书）

| 等级 | 含义 |
|------|------|
| A | 有具体数字可查，出处是荟萃分析、大型队列或 RCT |
| B | 有研究支持但说不出确切数字；或小样本、单项研究 |
| C | 作者经验或公认做法，无直接文献 |

## "口径"设计（本书特有）

原书四口径：寿命/时间与精力/金钱/人身自由。
本书改为：**成绩 / 金钱 / 时间 / 心理**。

- **成绩**：学业表现变化（标准化测验、GPA、升学结果）
- **金钱**：教育支出省下或花掉多少
- **时间**：家长和孩子的时间被占掉多少
- **心理**：孩子的心理健康、亲子关系、学习动机

**四口径分开算，不互相折算。** "成绩提高"和"省下 5 万"不在一把尺子上。

## 关键设计决策

1. **不重复原书**：身体安全窗口（近视/脊柱/欺凌/抑郁）指回原书第 30 节，本书只写学业和心理
2. **争议必须呈现**：成长型思维、补习效果都有大争议，正反方都写
3. **"普娃"定义**：成绩在中等区间（约 40-70 百分位）的孩子。不写牛娃也不写特殊需要儿童
4. **诚实标注**：教育研究多为观察性研究（非 RCT），因果性弱，备注里必须说明
5. **中国语境优先**：能引国内数据（CEPS/PISA 中国/教育部文件）优先，国外研究标注国别
